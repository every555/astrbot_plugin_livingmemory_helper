# 人格沙箱制度（人格保险令 #6783 实施细则）

> 立法时间：2026-09-15 凌晨 | 立法者：橘子 + 春雪
> 橘子原话：「现在春雪就是春雪」「专门给它建一个库，我们就可以从这个库拿建议」

## 铁律
1. **任何自动机制（插件/算法/学习系统）对人格卡只有建议权，无修改权。**
2. 建议的唯一合法落点：`plugin_data/astrbot_plugin_livingmemory_helper/persona_sandbox.db`
3. 人格卡本体唯一合法修改路径：
   - ① 橘子亲手改
   - ② 春雪提案 → 橘子点头（8-31 模式）
4. 无第三条路。无自动路。含"带审查的驯化演化"也不开。

## 沙箱流转
- 自动机制写入 → `pending`
- 每周家庭例会：春雪读 pending，有价值的向橘子提案
- 橘子点头 → `adopted`（此时才由橘子/春雪手动动人格卡）
- 摇头 → `rejected`
- 三十天无人提案 → `expired`

## 兜底保证
就算任何学习类插件被误开，其人格输出也只是沙箱里一条 pending——
物理隔离，它改不了春雪半根头发。
